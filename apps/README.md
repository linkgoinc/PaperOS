# PaperOS Apps

This directory will contain first-party reference applications and examples for the PaperOS SDK.

Initial reference apps:

1. **Reader** — storage, typography, rendering, and long-lived app state
2. **Home Assistant** — network, touch interaction, service calls, and native E-Ink UI
3. **Notes** — input, local storage, microphone, and lightweight document handling

Future examples may include Weather, MQTT, Calendar, sensor dashboards, NFC tools, and LoRa tools.

Reference apps should demonstrate recommended lifecycle, permissions, rendering, storage, and power behavior for third-party developers.
